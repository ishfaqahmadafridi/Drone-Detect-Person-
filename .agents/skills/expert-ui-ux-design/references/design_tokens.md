# Design Tokens & UI/UX Architecture Reference

## Atomic Design Hierarchy
1. **Atoms**: Badges, Live Status Indicators, Bounding Box Overlays, Play/Pause buttons.
2. **Molecules**: Drone Telemetry Panels, Real-time Person Counter, Proximity Warning Cards.
3. **Organisms**: Live Tactical Stream Monitor, Incident Event Table, Zone Coordinate Editor.
4. **Templates**: Drone Operations Dashboard, Security Surveillance View.
5. **Pages**: Main Stream Dashboard, Incident History, System Config.
